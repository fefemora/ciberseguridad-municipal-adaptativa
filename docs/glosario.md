# Glosario

Términos del proyecto de título y siglas utilizadas en la documentación del MCA.

| Término | Definición |
| --- | --- |
| Análisis de brechas (*gap analysis*) | Comparación entre el estado actual y el estado deseado para priorizar las acciones pendientes. |
| As-Is | Estado actual. En el diagnóstico de la tesis se estima mediante evidencia documental. |
| BCP | Plan de continuidad del negocio. Organiza la continuidad de los servicios críticos durante una interrupción. |
| CGR | Contraloría General de la República de Chile. Organismo de control de la Administración del Estado. |
| CID | Confidencialidad, integridad y disponibilidad. Objetivos de protección de la información. |
| Ciberseguridad | Protección de sistemas, servicios y datos frente a riesgos e incidentes digitales. |
| CIS Controls | Conjunto de controles y salvaguardas de ciberseguridad del Center for Internet Security. |
| CIS IG1 | Primer grupo de implementación de CIS. Reúne salvaguardas básicas de higiene de ciberseguridad. |
| CISO | Responsable de dirigir la estrategia y la gobernanza de seguridad de la información de una organización. |
| Código abierto | Software distribuido bajo una licencia que permite acceder a su código fuente, modificarlo y redistribuirlo conforme a sus términos. |
| CVE | Identificador de una vulnerabilidad específica divulgada públicamente. |
| CWE | Clasificación de tipos de debilidades que pueden dar origen a vulnerabilidades. |
| DRP | Plan de recuperación ante desastres. Define cómo restaurar sistemas, datos y servicios tras una interrupción grave. |
| DS N.º 83 de 2004 | Decreto de SEGPRES sobre seguridad y confidencialidad de los documentos electrónicos, publicado en 2005 y citado en la tesis. [Ficha de la BCN](https://www.bcn.cl/leychile/navegar?idNorma=234598). |
| Fuentes abiertas | Información accesible públicamente que se utiliza en el diagnóstico documental, como informes y organigramas. |
| KPI | Indicador clave de desempeño. Mide el avance o desempeño de una actividad, como la cobertura de inventario. |
| Log | Registro de eventos generado por un sistema, servicio o aplicación. |
| MCA | Modelo de Ciberseguridad Adaptativo. Propuesta de la tesis para municipalidades chilenas de categorías 3 y 4. |
| NIST CSF | Marco de ciberseguridad del NIST. El proyecto usa como referencia la estructura de cinco funciones de CSF 1.1. |
| NIST Tier 1 | Nivel Parcial. Punto de partida inferido en la tesis para orientar el análisis. |
| NIST Tier 2 | Nivel Informado por el Riesgo. Estado objetivo propuesto por el MCA. |
| ORC | Oficial de Riesgo y Cumplimiento. Rol que supervisa riesgos, compromisos y evidencias del modelo. |
| OSL | Oficial de Seguridad Lógico. Rol que coordina la ejecución de los controles técnicos del MCA. |
| OSINT | Obtención y análisis de información de fuentes abiertas. En el MCA se aplica a la revisión documental. |
| PE | Patrocinador Ejecutivo. Rol que respalda el modelo y aprueba decisiones institucionales. |
| Phishing | Engaño que suplanta a una persona o entidad para inducir una acción, como entregar información o abrir un enlace. |
| RACI | Matriz que identifica al ejecutor (R), al aprobador (A), a quien se consulta (C) y a quien se informa (I). |
| Ransomware | Ataque que restringe el acceso a sistemas o datos y puede incluir extorsión por su acceso o divulgación. |
| SIEM | Gestión de información y eventos de seguridad. Centraliza y analiza registros y alertas. |
| SUBDERE | Subsecretaría de Desarrollo Regional y Administrativo de Chile. |
| To-Be | Estado deseado. En el MCA, corresponde al objetivo de gestión informada por el riesgo. |
| TTAP | Tiempo de aplicación de parches. Días entre la disponibilidad de un parche crítico y su instalación. |
| Vulnerabilidad | Debilidad que puede ser aprovechada para comprometer un activo, sistema o servicio. Su gestión corresponde al [control CIS 7](controles-cis.md). |
| Wazuh | Plataforma de código abierto para monitoreo de seguridad y análisis de eventos. |

Base documental: glosario del proyecto de título, con términos adicionales usados en el repositorio.
