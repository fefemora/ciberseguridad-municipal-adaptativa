# Versiones y citación

La primera edición del repositorio, `v1.0.0`, se publicó el 18 de noviembre de 2026 en [GitHub Releases](https://github.com/fefemora/ciberseguridad-municipal-adaptativa/releases/tag/ciberseguridad), bajo la etiqueta de Git `ciberseguridad`. El proyecto de título está fechado el 29 de noviembre de 2025.

- [Edición documentada para GitHub](https://github.com/fefemora/ciberseguridad-municipal-adaptativa/releases/download/ciberseguridad/Modelo_Ciberseguridad_Adaptativo_git_ver_v1.0.0.pdf).
- [Proyecto de título académico](https://github.com/fefemora/ciberseguridad-municipal-adaptativa/releases/download/ciberseguridad/Proyecto_de_Titulo_Fernando_Mora_acad_ver._v1.0.0.pdf).

| Ejemplo | Tipo de cambio |
| --- | --- |
| `v1.0.1` | Corrección editorial que conserva el contenido técnico. |
| `v1.1.0` | Ampliación compatible, como una plantilla o un anexo nuevo. |
| `v2.0.0` | Cambio sustantivo al modelo o a su metodología. |

Cada edición tendrá una publicación independiente en [Releases](https://github.com/fefemora/ciberseguridad-municipal-adaptativa/releases), con sus notas de cambios y sus propios archivos descargables. Para reutilizar el modelo, consulta las notas y descarga el PDF de la edición que quieras aplicar.

## Cómo citar

Para citar una edición publicada, registra autor, año de publicación, título, versión y DOI específico de esa edición. Si todavía carece de DOI, usa el enlace directo a su publicación en GitHub.

Para citar el trabajo académico original, usa el título oficial, la fecha académica, la institución y el enlace institucional si está disponible.
